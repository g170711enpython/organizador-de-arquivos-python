# 🗂️ Organizador de Arquivos Automático

Um script inteligente em **Python** que organiza automaticamente sua pasta de Downloads (ou qualquer outra) movendo arquivos para pastas específicas baseadas na extensão (.jpg, .pdf, .exe, etc.).

Desenvolvido para economizar tempo e manter a organização do seu computador.

## ✨ Funcionalidades

- **Detecção Automática:** Identifica a extensão de cada arquivo.
- **Criação Inteligente:** Cria as pastas de destino (Imagens, Documentos, Programas) se elas não existirem.
- **Multi-formato:** Suporta imagens, documentos, instaladores, códigos e arquivos compactados.
- **Simples e Rápido:** Executa em segundos.
